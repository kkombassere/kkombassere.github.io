FasoRoots — Site vitrine (statique)
=======================================

Contenu généré automatiquement. Déployez le dossier `fasoroots_site` tel quel (Netlify, Vercel, GitHub Pages, OVH, etc.).

Fichiers principaux :
- index.html : page d’accueil
- construction.html : page de maintenance/construction
- assets/ : images (logo, photo, favicon, GIF animé)
- styles.css : styles légers (palette FasoRoots)
- app.js : JS minimal (défilement fluide)

Éditez vos coordonnées dans `index.html` (section #contact).

Conseils de déploiement rapide :
1) GitHub → nouveau repo → push du dossier. 
2) Netlify → "Add new site" → Import from Git → build command: none, publish directory: `fasoroots_site`.
3) Vercel → "New Project" → import → Framework: Other → Output: `fasoroots_site`.

Astuce : Pour afficher la page de construction sur tout le site, redirigez `/` vers `/construction.html` côté hébergeur le temps des travaux.
